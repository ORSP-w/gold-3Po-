# Подключение GOLD-3Po к MetaTrader 5

GOLD-3Po подключается к терминалу MT5 вашего брокера, получает котировки золота,
рассчитывает уровни ликвидности и передаёт их **отдельному индикатору** на график.
Приложение не отправляет и не изменяет ордера.

## Архитектура

```
GOLD-3Po (Electron)                    MetaTrader 5
┌─────────────────────────┐            ┌──────────────────────────┐
│ Вход: счёт/сервер/пароль│──офиц. SDK─▶│ терминал брокера          │
│ зоны по ТФ из настроек  │            │                          │
│ публикация снапшота     │──файл─────▶│ индикатор Gold3PoLevels  │
└─────────────────────────┘  Common    │ рисует уровни на графике │
                             Files     └──────────────────────────┘
```

- Вход выполняется официальным Python-модулем MetaTrader5, который упакован в
  автономный `mt5-runtime/gold3po-mt5/gold3po-mt5.exe` внутри установщика — отдельный Python не нужен.
- Пароль передаётся модулю через stdin и **не сохраняется** в файлах приложения.
- Уровни публикуются атомарно в `…\MetaQuotes\Terminal\Common\Files\GOLD3PO\<СИМВОЛ>.csv`
  (символ в верхнем регистре, например `XAUUSDM.csv`). Индикатор читает этот файл
  каждые 2 секунды; сети не использует и DLL не требует.
- Лицензия GOLD-3Po проверяется при каждом обновлении: без действующего ключа
  публикация прекращается и индикатор очищает уровни по таймауту.

## Два способа подать котировки

| | Вход из приложения (по умолчанию) | Советник `Gold3PoBridge` |
|---|---|---|
| Что нужно | `terminal64.exe`, счёт, сервер, пароль (лучше инвесторский) | уже открытый терминал, разрешённый WebRequest, токен моста |
| История при старте | ~8 часов или 25 000 тиков от терминала | до 90 дней (по умолчанию 30) |
| Кто получает данные | приложение и индикатор через файл-снапшот | приложение по HTTP; зоны советник может рисовать сам |
| Токен | не нужен — вход выполняет приложение | **⚙ Настройки → Отрисовка в MT5 → Мост MT5**, кнопка «Скопировать» |

Оба пути можно держать включёнными одновременно: советник доливает глубокую историю, вход из приложения продолжает живой поток. Повторы отсекаются на стороне API по идентификатору события, поэтому перезапуск советника не ломает нумерацию живых котировок.

## Пошагово

1. Активируйте лицензию GOLD-3Po (экран активации, Machine ID → ключ).
2. Нажмите **«Подключить MT5»** → **«Выбрать…»** и укажите `terminal64.exe`
   терминала вашего брокера (например, RoboForex MT5).
3. Заполните номер счёта, **точное имя сервера** из окна входа MT5, пароль и
   символ золота на графике (например `XAUUSD`, `XAUUSDm`, `XAUUSD.pro`).
   Рекомендуется демо-счёт или **пароль инвестора** (только чтение).
4. Нажмите **«Подключить»**. Приложение запустит терминал при необходимости,
   выполнит вход и подтвердит счёт/сервер/символ. Статус станет «online».
5. Нажмите **«Скопировать индикатор в MT5»**. Если рядом с терминалом есть
   MetaEditor, индикатор скомпилируется автоматически; иначе откройте
   `MQL5\Indicators\Gold3PoLevels.mq5` в MetaEditor и нажмите F7.
6. В MT5 обновите «Навигатор → Индикаторы» и перетащите **Gold3PoLevels** на
   график золота. Уровни появятся в течение нескольких секунд и будут
   обновляться по мере поступления котировок. По умолчанию зоны рисуются
   **красными сплошными линиями** (верхняя и нижняя граница зоны) с подписью
   «тип уровня | состояние | сила %».
7. Цвета, стиль и толщину линий, заливку, подписи, количество зон (по умолчанию
   3–7) и таймфрейм меняйте в приложении: **⚙ Настройки → Отрисовка в MT5 / Зоны**.
   Индикатор подхватывает изменения в течение ~5 секунд без перезапуска.
   Чтобы задать стиль вручную в самом MT5, выключите вход `InpUseAppStyle`.

## Трей

Сворачивание и закрытие окна прячут приложение в трей — локальный сервис и
поток котировок продолжают работать. «Open» / двойной клик по иконке возвращают
окно; **«Exit»** полностью завершает приложение и очищает снапшот уровней.

## Если MT5 не подключается

Окно показывает причину, которую сообщает сам терминал, — своего текста про
«проверьте путь» там больше нет:

- **«Модуль подключения MT5 не найден: <путь>»** — сборка пришла без коннектора;
  лечится переустановкой, а не настройками.
- **«MT5 rejected the login: account N is not authorized on <сервер> (Invalid
  account)»** — брокер не пускает этот счёт. Терминал при этом уже запущен и
  стоит на окне входа: откройте MT5, войдите в счёт вручную (или откройте
  демо на сервере, где он есть), дождитесь котировок и нажмите «Подключиться»
  снова. Журнал MT5 (вкладка «Журнал») показывает то же самое — приложение
  читает его и повторяет причину словами брокера.
- **«Could not attach to MT5. Open MT5 by hand, log in, wait for quotes…»** —
  терминал не ответил за 15 секунд: обычно он ещё грузится, висит на диалоге
  входа или запущен под другим пользователем Windows (в том числе «от
  администратора», когда GOLD-3Po — нет).

## Важные ограничения

- Вход через официальный SDK может **запустить терминал и переключить активный
  счёт** в выбранной установке. Используйте отдельную установку терминала для
  GOLD-3Po, если не хотите затрагивать рабочий терминал с советниками.
- MFA, сертификаты и принудительная смена пароля выполняются в самом MT5.
- Зоны — ценовые области, где рынок уже разворачивался. Уровни собираются из
  нескольких независимых источников на закрытых барах выбранного таймфрейма:
  свинги, максимум и минимум прошлого дня, экстремумы сессий Азия / Лондон /
  Нью-Йорк, открытие и экстремумы прошлой недели, свинги H1 и H4, профиль объёма
  (POC и границы зоны стоимости) и круглые цены. Совпадение нескольких
  источников поднимает силу зоны. Все расстояния считаются в ATR. Уровень,
  пробитый один раз, остаётся как «role flip» (поддержка ↔ сопротивление);
  уровень, который цена пробивала туда-обратно, удаляется. Сила 0–100 % —
  рейтинг по измеренной реакции, касаниям, свежести, объёму, совпадению
  источников и близости к цене, а не откалиброванная вероятность. Это не стакан
  и не гарантия реакции цены.

## Формат снапшота (G3P2)

`Common\Files\GOLD3PO\<SYMBOL>.csv`, CRLF:

```
G3P2,<unix-время>,<символ>,<число зон>
STYLE,<#цвет выше>,<#цвет ниже>,<SOLID|DASH|DOT|DASHDOT|DASHDOTDOT>,<толщина 1-5>,<заливка 0/1>,<подписи 0/1>,<сила 0/1>
<id>,<buy-side|sell-side>,<low>,<high>,<сила 0-1>,<состояние>,<подпись>
...
END
```

Индикатор также принимает старый формат G3P1 (без строки STYLE).
- Поля «состояние» и «подпись» пишутся по-русски теми же словами, что и в панели
  приложения («Максимум прошлого дня», «ПРОВЕРЕНА»): подпись на графике MT5 и
  список зон в приложении читаются одинаково. Запятые, вертикальные черты и
  управляющие символы из подписи вырезаются, поэтому CSV не ломается.
  Файл пишется в UTF-8; индикатор читает его с кодовой страницей CP_UTF8.
- История при подключении ограничена последними ~8 часами тиков брокера
  (до 25 000 тиков); далее поток накапливается. Если терминал отдал не весь
  поток, приложение пишет об этом в строке состояния MT5 («История MT5
  неполная»), а не выдаёт частичные данные за полные. Для глубокого бэктеста
  используйте отдельный EA-мост `Gold3PoBridge.mq5` (до 90 дней).
- EA-мост и индикатор можно использовать вместе: EA грузит историю и тики,
  индикатор рисует уровни из файла приложения.
