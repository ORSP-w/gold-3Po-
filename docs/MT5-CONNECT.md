# Подключение GOLD-3Po к MetaTrader 5

GOLD-3Po подключается к терминалу MT5 вашего брокера, получает котировки золота,
рассчитывает уровни ликвидности и передаёт их **отдельному индикатору** на график.
Приложение не отправляет и не изменяет ордера.

## Архитектура

```
GOLD-3Po (Electron)                    MetaTrader 5
┌─────────────────────────┐            ┌──────────────────────────┐
│ Вход: счёт/сервер/пароль│──офиц. SDK─▶│ терминал брокера          │
│ расчёт зон по M15       │            │                          │
│ публикация снапшота     │──файл─────▶│ индикатор Gold3PoLevels  │
└─────────────────────────┘  Common    │ рисует уровни на графике │
                             Files     └──────────────────────────┘
```

- Вход выполняется официальным Python-модулем MetaTrader5, который упакован в
  автономный `gold3po-mt5.exe` внутри установщика — отдельный Python не нужен.
- Пароль передаётся модулю через stdin и **не сохраняется** в файлах приложения.
- Уровни публикуются атомарно в `…\MetaQuotes\Terminal\Common\Files\GOLD3PO\<СИМВОЛ>.csv`
  (символ в верхнем регистре, например `XAUUSDM.csv`). Индикатор читает этот файл
  каждые 2 секунды; сети не использует и DLL не требует.
- Лицензия GOLD-3Po проверяется при каждом обновлении: без действующего ключа
  публикация прекращается и индикатор очищает уровни по таймауту.

## Пошагово

1. Активируйте лицензию GOLD-3Po (экран активации, Machine ID → ключ).
2. Нажмите **«Подключить MT5»** → **«Выбрать…»** и укажите `terminal64.exe`
   терминала вашего брокера (например, RoboForex MT5).
3. Заполните номер счёта, **точное имя сервера** из окна входа MT5, пароль и
   символ золота на графике (например `XAUUSD`, `XAUUSDm`, `XAUUSD.pro`).
   Рекомендуется демо-счёт или **пароль инвестора** (только чтение).
4. Нажмите **«Подключить»**. Приложение запустит терминал при необходимости,
   выполнит вход и подтвердит счёт/сервер/символ. Статус станет «online».
5. Нажмите **«Скопировать индикатор в MT5»**. Если рядом с терминалом есть
   MetaEditor, индикатор скомпилируется автоматически; иначе откройте
   `MQL5\Indicators\Gold3PoLevels.mq5` в MetaEditor и нажмите F7.
6. В MT5 обновите «Навигатор → Индикаторы» и перетащите **Gold3PoLevels** на
   график золота. Уровни появятся в течение нескольких секунд и будут
   обновляться по мере поступления котировок. Число зон задаётся в приложении
   («Зон отображать», 1–20) и дублируется входом индикатора `InpMaxZones`.

## Трей

Сворачивание и закрытие окна прячут приложение в трей — локальный сервис и
поток котировок продолжают работать. «Open» / двойной клик по иконке возвращают
окно; **«Exit»** полностью завершает приложение и очищает снапшот уровней.

## Важные ограничения

- Вход через официальный SDK может **запустить терминал и переключить активный
  счёт** в выбранной установке. Используйте отдельную установку терминала для
  GOLD-3Po, если не хотите затрагивать рабочий терминал с советниками.
- MFA, сертификаты и принудительная смена пароля выполняются в самом MT5.
- Зоны — эвристика повторных свингов на закрытых M15-барах (состояния
  UNTESTED / TESTED / SWEPT / NEAR PRICE; пробой закрытием убирает зону).
  Это не стакан и не гарантия реакции цены.
- История при подключении ограничена последними ~8 часами тиков брокера
  (до 25 000 тиков); далее поток накапливается. Для глубокого бэктеста
  используйте отдельный EA-мост `Gold3PoBridge.mq5` (до 90 дней).
- EA-мост и индикатор можно использовать вместе: EA грузит историю и тики,
  индикатор рисует уровни из файла приложения.
